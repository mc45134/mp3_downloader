# MP3 音樂下載器

輸入歌手／藝人／團體名 → 列出所有歌曲與專輯 → 勾選 → 程式逐首到 YouTube 搜尋、下載並統一轉成 MP3。

## 使用方法

1. 啟動（二選一）：
   - 雙擊「開始下載MP3.bat」：會出現一個黑色視窗跑伺服器，並自動開啟瀏覽器。下載期間請保留該視窗。
   - 雙擊「背景啟動(無視窗).vbs」：完全背景執行、沒有視窗，自動開啟瀏覽器。
   - 第一次執行會先安裝依賴，需等一會。
2. 輸入歌手名稱搜尋，點一下相符的歌手。
3. 在歌曲列表勾選想要的歌（可用「全選」、逐專輯全選、或輸入關鍵字篩選）。
4. 按「開始下載所選歌曲」，下方會顯示每首歌的搜尋、下載、轉檔進度。
5. 完成的 MP3 會儲存在「下載」資料夾內，每張專輯一個子資料夾（可於 config.json 修改 output_dir）。
6. 結束伺服器：執行「停止下載器.bat」（或直接關閉黑色視窗）。

⚠ 注意：不要直接雙擊 index.html 開啟——必須透過上面任一個啟動檔，否則網頁連不到伺服器，搜尋會失敗。

## 檔案說明

- 開始下載MP3.bat — 啟動程式（有視窗）
- 背景啟動(無視窗).vbs — 啟動程式（背景、無視窗）
- 停止下載器.bat — 關閉伺服器
- app.py — 後端（伺服器 + 下載引擎）
- index.html — 網頁介面
- config.json — 設定（儲存位置、地區、音質），第一次啟動後自動產生

## 備註

- 所有下載好的 MP3 會放在「下載」資料夾，每張專輯一個子資料夾；每個專輯資料夾內附「下載記錄.txt」，逐首記錄歌曲、專輯、來源（YouTube、Bilibili 等）、影片標題、頻道和實際下載連結。
- 歌單資料來自 iTunes 音樂庫，下載音訊來自 YouTube 搜尋，請注意僅下載有權存取的內容。
- 音質預設 320kbps MP3，並自動寫入歌名、歌手、專輯標籤與專輯封面。
- 若某首歌抓不到，通常是 YouTube 上搜尋不到對應音訊，可稍後重試。
- 伺服器位址：http://127.0.0.1:8765（被佔用時會自動改用 8766、8767…）
